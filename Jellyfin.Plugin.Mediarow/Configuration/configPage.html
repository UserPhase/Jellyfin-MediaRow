Streaming

Stream Provider

How a title is turned into a playable stream.

None: Browse content without streaming capability.
Embedarr: Use Embedarr to generate STRM files and stream.
Direct: Use custom URL templates for direct streaming.
AIOStreams: Use playable HTTP streams from your configured Stremio addon. Raw torrent/info-hash entries are not supported.

AIOStreams Settings

Your AIOStreams instance and how its results are picked.

Your full AIOStreams addon URL including the encrypted configuration.
Enable Persistence and automatic library scanning below. Set the Movies and Series paths, then add those exact folders as Jellyfin libraries. Selected titles are saved as small STRM/metadata files, not downloaded videos. Jellyfin probes the chosen stream for audio, subtitles, and transcoding.
Get yours from:
  • Self-hosted: Your AIOStreams instance configuration page
  • ElfHosted: elfhosted.com/app/aiostreams

How it works

AIOStreams is a Stremio addon aggregator that handles stream discovery and delivery.
Configure your sources (debrid services, torrent indexers, NZB via NZBDav) in AIOStreams,
then paste your addon URL here. The plugin will query AIOStreams for available streams
when you play content.

Moves AIOStreams results in the title's original language (for example English for Smallville) to the top, so they play by default, and selects the original-language audio track in multi-audio releases. Results tagged only with other languages (such as a Russian dub) move to the bottom. Unlabeled results keep their order.
Probe HLS streams to extract accurate duration. Helps with scrubbing on Android TV and other players. Disable if experiencing playback issues (some streams use one-time tokens that are invalidated by probing).

Direct URL Templates

Configure URL templates for direct streaming. Available placeholders:
{id} - Preferred ID (based on Provider ID Preferences below)
{imdb} - IMDB ID (e.g., tt1234567)
{tmdb} - TMDB ID (numeric, movies only)
{tvdb} - TVDB ID (numeric, TV/anime only)
{anilist} - AniList ID (numeric, anime only)
{season} - Season number
{episode} - Episode number
{absolute} - Absolute episode number (anime only)
{audio} - Audio type: "sub" or "dub" (anime only, requires Sub/Dub Selection enabled)
{title} - URL-encoded title

Template for movie streams. Placeholders: {id}, {imdb}, {tmdb}, {title}
Template for TV episodes. Placeholders: {id}, {imdb}, {tvdb}, {season}, {episode}, {title}
Template for anime episodes. Placeholders: {id}, {imdb}, {tvdb}, {anilist}, {season}, {episode}, {absolute}, {audio}, {title}
When enabled, generates stream URLs even for movies or episodes that haven't been released yet. When disabled (default), unreleased content cannot be played.

      Library & playback

      Skip Intro & Next Episode

      Netflix-style "Skip Intro", "Skip Recap" and a "Next Episode" prompt when the credits start. Works in Jellyfin Web and in apps that support media segments (Android TV, Swiftfin, Findroid and others).

      Looks up episodes in AniSkip (anime), TheIntroDB and IntroDB; no API key needed. Applies to every episode without markers of its own, so markers from a plugin such as Intro Skipper always take priority. Times are community-submitted and can be a few seconds off for a different release.
      Restyles the skip button and the up-next card. When the credits start, the next episode plays after a 10-second countdown (the "Start Now" button fills up), like Netflix, instead of after the credits. Requires "Play next episode automatically" in the user's playback settings. Each user can choose to skip automatically under Settings → Playback → Media segments. Reload the web page after changing this.

      • TV Shows: /mediarow/tv

      Home

      Virtual Home Rows

      Renders virtual Popular and genre rows through Mediarow. Items are fetched dynamically and are not imported into the Jellyfin library.

      Publishes each row as a virtual library so Android TV, Swiftfin, Findroid, Kodi and Samsung Tizen apps show them as "Latest" rows. Browsers and the Android/iOS/desktop apps already show the full Mediarow Home.
      Off by default to avoid showing every row twice in the browser.
      What kind of content do you want displayed?
      Movies and series are enabled by default. Anime is separate: enable it to include anime movies and series identified by your provider's metadata.
      Home rows and order:
      Home shows separate Popular rows and the first six checked genres, alternating movie and series categories (plus Anime if enabled). Category filters show every checked genre for that content type. Your row order is preserved in both views.
      Check the rows to show, then drag checked rows into order. Up/Down buttons also work with a keyboard or on a phone. Save, then return to Home to apply the changes without restarting Jellyfin.
      Existing advanced sections are kept when you save. Use Science Fiction for sci-fi and Anime for anime.
      The same row remains stable during the refresh interval.
      Set to 0 to disable the rating filter.

      Watched item cleanup (optional)

      Removes imported Mediarow items after they are watched.

      Both options are off by default. An hourly scheduled task removes generated STRM/NFO files and their library entries only after every enabled user with access has watched them. Series must be marked Ended by Jellyfin metadata and every episode (including specials) must be watched. Ongoing or unknown-status series, favorites, active playback, unindexed streams, and folders containing other media are kept. Files changed within the last ten minutes are kept until a later run. Artwork and subtitles are left on disk. Removal affects the shared library; watching again requires reimporting.
