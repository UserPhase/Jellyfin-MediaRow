Streams play through this server, so when a debrid link expires (for example after a long pause) or a host briefly fails, Mediarow fetches a fresh link for the same file and playback continues. Library & cleanup

Choose where small stream files are created and when to remove watched titles.

Keep only what you save

Use Jellyfin's Favorite heart to keep a movie or series for later. A favorite from any user keeps the shared title.

Automatically remove temporary Mediarow STRM/NFO files and library entries after browsing or playback. Started, unfinished series are kept between episodes automatically, including ongoing shows waiting for more episodes. Simply opening a poster does not protect it. Use Jellyfin's Favorite heart to keep other titles for later. A favorite from any user keeps the shared title. Off by default.
Minutes since the last reported activity. Default: 5. Active and paused playback are protected.
How cleanup works
Default: 5 minutes. Wait this long after the last title interaction or playback activity. Active or paused playback and imports are protected. A started series stays protected until it is ended, its complete episode inventory is verified, and everyone who started it has finished all imported episodes. Unknown or incomplete metadata keeps it protected. Cleanup checks once a minute, so removal can occur up to about a minute after the grace period. Restarting the server grants a fresh grace period. Works through Jellyfin's saved playback history and standard requests from Android TV and other clients; no custom client button is needed. Clients do not always report leaving a details page, so the timer uses the last reported title activity. Only indexed Mediarow-generated streams and companion NFO files are removed; artwork and subtitles remain.

When enabled, this policy takes priority over cleanup after watching. Your watched-cleanup choices are kept.

Automatically trigger a library scan after creating new items.
When enabled, creates persistent media even for movies and shows that haven't been released yet. When disabled (default), only creates media for content that has been released.

Cleanup after watching

Remove generated Mediarow files and library entries after watching. Favorites are kept.

If Remove unsaved titles is enabled above, its grace-period cleanup takes priority. Both options are off by default. An hourly scheduled task removes generated STRM/NFO files and their library entries only after every enabled user with access has watched them. Series must be marked Ended by Jellyfin metadata and every episode (including specials) must be watched. Ongoing or unknown-status series, favorites, active playback, unindexed streams, and folders containing other media are kept. Files changed within the last ten minutes are kept until a later run. Artwork and subtitles are left on disk. Removal affects the shared library; watching again requires reimporting.

New episodes

Adds newly released episodes of saved Mediarow series in the background, so they show up in Next Up without opening the show.

The "Mediarow: Sync New Episodes" task runs hourly and only re-checks a show when it is due: on the interval below, right after a known air date, weekly for ended shows, and with a growing delay after errors.

Language & subtitles

Set audio and subtitle preferences for each user, with optional per-series choices.

Original language

Moves AIOStreams results in the title's original language (for example English for Smallville) to the top, so they play by default, and selects the original-language audio track in multi-audio releases. Results tagged only with other languages (such as a Russian dub) move to the bottom. Unlabeled results keep their order.

This is the default for AIOStreams playback. Enabled per-user language preferences below take priority.

Skip intro & next episode

Netflix-style "Skip Intro", "Skip Recap" and a "Next Episode" prompt when the credits start. Works in Jellyfin Web and in apps that support media segments (Android TV, Swiftfin, Findroid and others).

Looks up episodes in AniSkip (anime), TheIntroDB and IntroDB ; no API key needed. Applies to every episode without markers of its own, so markers from a plugin such as Intro Skipper always take priority. Times are community-submitted and can be a few seconds off for a different release.
Restyles the skip button and the up-next card. When the credits start, the next episode plays after a 10-second countdown (the "Start Now" button fills up), like Netflix, instead of after the credits. Requires "Play next episode automatically" in the user's playback settings. Each user can choose to skip automatically under Settings → Playback → Media segments. Reload the web page after changing this.
